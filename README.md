# chijiokealim.dev

Personal portfolio site built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Push to GitHub and import on [vercel.com/new](https://vercel.com/new). No configuration needed.

## Customization

All content lives in `app/page.tsx` — projects, experience, skills, and contact info are defined as data arrays at the top of the file. Update the `PROJECTS`, `EXPERIENCE`, and `SKILLS` constants to change what's displayed.

Drop a resume PDF at `public/Chijioke_Alim_Resume.pdf` for the Resume button to work.
